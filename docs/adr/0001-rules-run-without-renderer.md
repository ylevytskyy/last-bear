# 0001 — Правила гри працюють без рендеру

Правила гри (рух, Blink, Рефлекс, Удар, Серця, вороги, Ключ, Клітка) живуть в окремому шарі, що крокує фіксованим кроком часу і не знає про Three.js, DOM чи звук; рендер лише читає його стан. Це дозволяє автоматичному Проходженню грати Зріз від початку до кінця в тестах за секунди. Ціна: фізика Rapier мусить запускатися поза браузером, а кожен візуальний ефект, що впливає на правила (сповільнення часу, тривалість телепорту), задається в правилах, а не в анімації.

Відкинуто: логіка всередині об'єктів сцени з перевіркою через Playwright — тести залежать від таймінгів кадрів, а механіка гри і є таймінги.

Rapier у Node перевірено пробним скриптом 2026-11-15 (`@dimforge/rapier3d-compat` 0.21.0, Node 26). Переглянути, якщо зріз S0 покаже, що під Vitest це не працює.
